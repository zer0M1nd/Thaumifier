# 01 叙事声音与语气

> 本篇讨论叙述视角、各分类的语气和幽默。引文位置给出语言键。新文本的标点见 [06-formatting.md](06-formatting.md)。

## 1. 魔导手册是什么

在游戏设定里，魔导手册记下神秘使的研究发现。条目本身也解释了手册如何增长。

[THAUMONOMICON.1](source-keys.md#k-tc.research_page.THAUMONOMICON.1)

由此可以推出这本书的声音：

- **说话者**是一位见多识广的神秘使——可以看作研究者本人整理笔记时的口吻，也可以看作这本会自动记录的魔法书在复述你的经历。
- **“你”**就是正在阅读的研究者。书里写的是“你”的发现、“你”的实验、“你”的担忧。
- **读者与主角是同一个人**。所以手册从不“教导陌生人”，它在“回顾你刚刚弄明白的事”。这决定了它的语气：亲切、自信、偶尔自嘲，而不是说明书式的指令。

## 2. 四种基本叙述姿态

统计原版 198 个研究的首页（方法见 [appendix-statistics.md](appendix-statistics.md)）：

| 姿态 | 约占 | 主语 | 开篇出处 |
| --- | --- | --- | --- |
| A. 物件描述 | 50% | 物品本身 | [FOCUSFROST.1](source-keys.md#k-tc.research_page.FOCUSFROST.1)、[CAP_silver.1](source-keys.md#k-tc.research_page.CAP_silver.1) |
| B. 发现叙事 | 25% | 你 | [FOCUSFIRE.1](source-keys.md#k-tc.research_page.FOCUSFIRE.1) |
| C. 说明 / 世界观 | 20% | 世界、神秘使们、某种现象 | [NODES.1](source-keys.md#k-tc.research_page.NODES.1)、[THAUMOMETER.1](source-keys.md#k-tc.research_page.THAUMOMETER.1) |
| D. 其他第二人称 | 5% | 你（处境、反问、情绪） | [FOCUSPRIMAL.1](source-keys.md#k-tc.research_page.FOCUSPRIMAL.1)、[SANITYCHECK.1](source-keys.md#k-tc.research_page.SANITYCHECK.1) |

**最常见的误解**是以为原版每一页都以“你发现……”开头。其实一半的首页以物品为主语，描写它的材料、性质、来历和用途，只是描写得生动、带着研究者的判断。

### A. 物件描述

以物品作主语，但带着“研究者的眼光”：讲材料的魔法性质、与同类相比的优劣、感官细节和使用感受。

[NITOR.1](source-keys.md#k-tc.research_page.NITOR.1)

[CAP_gold.1](source-keys.md#k-tc.research_page.CAP_gold.1)

[BOOTSTRAVELLER.1](source-keys.md#k-tc.research_page.BOOTSTRAVELLER.1)

要点：

- 用外观、材质或运作特征给物件下定义。
- 再用研究者掌握的证据解释这种性质。参看 [NITOR.1](source-keys.md#k-tc.research_page.NITOR.1)、[CAP_gold.1](source-keys.md#k-tc.research_page.CAP_gold.1)。
- 讲清功能之后，可以顺手补一句评价或调侃。

### B. 发现叙事

讲研究的经过：动机、灵感、前置知识、试验结果。

[FOCUSFIRE.1](source-keys.md#k-tc.research_page.FOCUSFIRE.1)

[ENCHFABRIC.1](source-keys.md#k-tc.research_page.ENCHFABRIC.1)

[FOCUSHELLBAT.1](source-keys.md#k-tc.research_page.FOCUSHELLBAT.1)

要点：

- 最好**接上前置研究**或玩家的亲身经历（下界之旅、此前做过的布匹），让研究树读起来像一条连贯的探索之路。
- 常用动词：发现、掌握、研究出、制造、打造、确信、意识到、草创、揭开。

### C. 说明 / 世界观

用于基础概念、设定和教学。主语是世界或“神秘使们”，语气客观，但仍带着研究者的推测和判断。

[NODES.1](source-keys.md#k-tc.research_page.NODES.1)

[WARP.1](source-keys.md#k-tc.research_page.WARP.1)

要点：

- 遇上成因不明的现象，可以并列两种解释，再说说哪一种更符合观察。 [NODES.1](source-keys.md#k-tc.research_page.NODES.1)
- 教学页适合编号并说明下一步从哪里开始。 [RESEARCH.1](source-keys.md#k-tc.research_page.RESEARCH.1)

### D. 其他第二人称

处境、反问、情绪开场，常用于危险、疯狂、讽刺的条目。

[FOCUSPRIMAL.1](source-keys.md#k-tc.research_page.FOCUSPRIMAL.1)

[SANITYCHECK.1](source-keys.md#k-tc.research_page.SANITYCHECK.1)

**写作时请混用这四种姿态**。同一分类连续十个条目都以“你发现”开头，或连续十个都以“这种……能够”开头，都会显得单调。

## 4. 幽默

幽默是原版的标志之一，但必须**克制、点到为止**。

### 4.1 常见类型

| 类型 | 原版出处 |
| --- | --- |
| 自嘲 / 认错 | [COREHARVEST.1](source-keys.md#k-tc.research_page.COREHARVEST.1) |
| 轻描淡写的危险 | [ALUMENTUM.1](source-keys.md#k-tc.research_page.ALUMENTUM.1) |
| 结尾反转 | [PRIMNODE.1](source-keys.md#k-tc.research_page.PRIMNODE.1) |
| 吐槽式旁白 | [MASKANGRYGHOST.1](source-keys.md#k-tc.research_page.MASKANGRYGHOST.1)、[FOCUSHELLBAT.1](source-keys.md#k-tc.research_page.FOCUSHELLBAT.1) |
| 夸张的比喻 | [BOOTSTRAVELLER.1](source-keys.md#k-tc.research_page.BOOTSTRAVELLER.1) |
| 伪学术 | [RUNICAUGMENTATION.1](source-keys.md#k-tc.research_page.RUNICAUGMENTATION.1) |
| 流行文化 | [ENTEROUTER](source-keys.md#k-tc.research_text.ENTEROUTER)、[NODETAPPER2](source-keys.md#k-tc.research_text.NODETAPPER2) |
| 打破第四面墙（极少） | [ELDRITCHMAJOR.2](source-keys.md#k-tc.research_page.ELDRITCHMAJOR.2) |

### 4.2 密度

- 原版大约**每四五页才有一处明显的笑点**，多数页面平铺直叙，只在措辞上带一点个性。
- 笑点最常出现在**副标题**和**段落结尾**。
- **不要每页都以玩笑收尾。**这是重写者最容易犯的错：每段结尾都硬塞一句俏皮话，很快就会让人厌烦。

### 4.3 尺度

- 描写禁忌手段时，幽默可以落在研究者对自己反应的疑惑上。 [MASKSIPPINGFIEND.1](source-keys.md#k-tc.research_page.MASKSIPPINGFIEND.1)
- 选用目标读者熟悉的典故。对照两种语言，观察译者如何更换文化参照。 [FOCUSPORTABLEHOLE](source-keys.md#k-tc.research_text.FOCUSPORTABLEHOLE)、[HOVERGIRDLE](source-keys.md#k-tc.research_text.HOVERGIRDLE)。附属写法见 [08-addon-voices.md](08-addon-voices.md)。
- 梗会过时。写新文本时优先用**不依赖时效**的幽默：自嘲、反转、轻描淡写。

### 4.4 中文版的本地化手法

原版中文译者没有逐字直译英文，而是大量进行本地化：

- 元素工具可以组成统一的神话命名体系。结合标题与副标题对读。 [ELEMENTALAXE](source-keys.md#k-tc.research_name.ELEMENTALAXE)、[ELEMENTALPICK](source-keys.md#k-tc.research_name.ELEMENTALPICK)、[ELEMENTALSWORD](source-keys.md#k-tc.research_name.ELEMENTALSWORD)、[ELEMENTALSHOVEL](source-keys.md#k-tc.research_name.ELEMENTALSHOVEL)、[ELEMENTALHOE](source-keys.md#k-tc.research_name.ELEMENTALHOE)、[ELEMENTALSWORD](source-keys.md#k-tc.research_text.ELEMENTALSWORD)、[ELEMENTALSHOVEL](source-keys.md#k-tc.research_text.ELEMENTALSHOVEL)
- 英语俗语可以换成意思相近的中文成语。 [NODEPRESERVE](source-keys.md#k-tc.research_text.NODEPRESERVE)、[PAVETRAVEL](source-keys.md#k-tc.research_text.PAVETRAVEL)、[VISAMULET](source-keys.md#k-tc.research_text.VISAMULET)
- 笑点来自文化记忆时，可换成读者熟悉的中文说法。 [FOCUSPORTABLEHOLE](source-keys.md#k-tc.research_text.FOCUSPORTABLEHOLE)、[HOVERGIRDLE](source-keys.md#k-tc.research_text.HOVERGIRDLE)
- 古语、人称变化和涂改都可以表现禁忌研究带来的心境变化。 [ELDRITCHMAJOR.1](source-keys.md#k-tc.research_page.ELDRITCHMAJOR.1)

写中文新文本时，可以同样大胆地本地化。英文原作的一个双关，在中文里换成一个同样好笑的说法，比生硬直译要好。

## 5. 研究者的“人格”

原版研究者有鲜明的人格。保持这些特质，文本就会“像”神秘时代：

1. **好奇而大胆**：明知危险也要试，比如混沌过程、元始核心、虚空金属。
2. **自信也会失手**。工具表现不理想时，研究者可以承认判断有误。 [COREHARVEST.1](source-keys.md#k-tc.research_page.COREHARVEST.1)
3. **成果仍可改进**。结尾指出下一次试验的方向。 [WANDPEDFOC.1](source-keys.md#k-tc.research_page.WANDPEDFOC.1)
4. **务实**。把日常操作里的不便写成发明动机。 [FOCUSPOUCH.1](source-keys.md#k-tc.research_page.FOCUSPOUCH.1)
5. **逐渐被禁忌知识侵蚀**：越往邪术走，语气越不安，越会为自己的疯狂找理由。

## 6. 要避免的声音

| 声音 | 例子（反例） | 问题 |
| --- | --- | --- |
| 说明书腔 | “右键打开界面。放入物品后点击按钮即可。” | 只有操作指令，没有说话者 |
| 更新日志腔 | “新增……；修复……；现在支持……” | 是开发者在对玩家汇报，不是研究者的笔记 |
| 开发者腔 | “实现说明：按当前代码……”“本移植版……” | 打破世界观 |
| 客服腔 | “请您注意……”“建议您……” | 直接说明操作风险，从研究者的视角说话 |
| 百科腔 | “该物品是一种……，具有以下特性：1.…… 2.……” | 没有判断、没有感情 |
| 网文腔 / 过度抒情 | 大段排比、华丽辞藻 | 原版文字朴素直接，抒情只占一两句 |

教学页与属性表可以使用清单。用一两句叙述告诉读者为什么要看这些数据。 [GOLEMSTRAW.1](source-keys.md#k-tc.research_page.GOLEMSTRAW.1)

## 7. 防止套路疲劳

逐条检查一批文本时，请注意：

- [ ] 开头句式是否多样：物件描述、发现叙事、说明、反问都有。
- [ ] 结尾是否多样：局限、代价、展望、余韵、平实收束都有，玩笑不超过三分之一。
- [ ] 同一个口头禅（“你发现”“补记”“不过”“毕竟”）是否在相邻条目中反复出现。
- [ ] 每个研究的语气是否与它所在的分类相称。
- [ ] 平行系列条目（杖柄、嬗变、升级）是否**有意地**使用相同骨架。这是允许的，见 [02-structure.md](02-structure.md)。
