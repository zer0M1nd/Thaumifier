# 附录：原版魔导手册文本统计

统计对象：神秘时代 4.2.3.5 简体中文 `zh_CN.lang` 中全部 307 段研究正文（`tc.research_page.*`）、199 个标题与副标题。字数为去掉 `<BR>`、`<LINE>`、`<IMG>` 与 `§` 格式码后的字符数（中文按字计，半角标点、数字、字母各计 1）。

这些数字用于“校准手感”：写完后对照一下，若你的页面普遍是原版的两三倍长、或每页都以同一种句式开头，就说明偏离了原版风格。

## 1. 单页正文长度

- 平均 106 字，中位数 102 字，最短 8 字，最长 248 字。
- 十分位：33、53、66、84、102、124、142、160、175。
- 也就是说：一半的页面在 102 字以内，90% 的页面不超过 175 字。原版单个语言键很少超过 250 字；内容多时，会拆成 `.1`、`.2`、`.3` 多个键（多页）。

| 标记 | 用量 |
| --- | --- |
| `<BR>` | 平均每页 1.7 个 |
| `<LINE>` | 21 页使用 |
| `<IMG>` | 25 页使用 |
| `§l`（粗体） | 83 次（多用于小标题与属性名） |
| `§n`（下划线） | 50 次（多用于小标题） |
| `§5`（紫色，标物品/设备名） | 30 次 |
| `§o`（斜体） | 2 次 |
| `§m`（删除线） | 1 次（仅邪术启示录的“涂改”效果） |

格式标记用得很克制：大多数页面只有一两个 `<BR>`，粗体与下划线主要用于小标题和属性表。
