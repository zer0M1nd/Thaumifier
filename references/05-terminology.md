# 05 术语与用词

> 按目标项目的显示名撰写。原版要素、分类及 455 条物品、方块和生物名称可在[术语索引](appendix-glossary.md)按键查询。

## 1. 译名优先级

1. **目标项目当前语言文件中的写法**：物品名、方块名必须与游戏里显示的名称逐字一致，玩家才能对上号。
2. 需要比对历史译名且已启用本体资源时，使用[术语索引](appendix-glossary.md)。
3. 缺少现成名称时，向作者核实，或在本文中为新概念选定一种写法。

不同语境里的译名可能不一致。下列出处适合用来核对。

## 3. 动作与操作用语

原版在按键操作上的写法比较随意，现代文本建议按下表统一：

| 操作 | 推荐写法 | 相关旧版用例 |
| --- | --- | --- |
| Right-click | 右击；需要强调时写“右键点击” | [JARLABEL.1](source-keys.md#k-tc.research_page.JARLABEL.1) |
| Left-click | 左击 | [RESEARCH.5](source-keys.md#k-tc.research_page.RESEARCH.5) |
| Sneak + right-click | 潜行右击 | [JARLABEL.2](source-keys.md#k-tc.research_page.JARLABEL.2) |
| Hold right-click | 按住右键 | [ELEMENTALSWORD.1](source-keys.md#k-tc.research_page.ELEMENTALSWORD.1) |
| Use (wand) on X | 对 X 使用法杖、用法杖右击 X、对着 X 挥舞法杖 | [CRUCIBLE.1](source-keys.md#k-tc.research_page.CRUCIBLE.1) |
| Middle click | 中键点击 | 按目标项目约定 |
| Keybind | 按下 F 键 / 按 V（默认） | [FOCUSFIRE.2](source-keys.md#k-tc.research_page.FOCUSFIRE.2) |
| Redstone | 通入红石信号、红石信号可控制其开闭 | [NODESTABILIZER.2](source-keys.md#k-tc.research_page.NODESTABILIZER.2) |
| Place / Break | 放置、拆除、破坏 | 按目标项目约定 |
| Bind / Link | 绑定、链接、连接 | [GOLEMBELL.2](source-keys.md#k-tc.research_page.GOLEMBELL.2) |

写按键时，先说**做什么**，再说**按什么**：“想清除所有标记，按下 F 键即可。”比“按 F：清除所有标记”更符合手册口吻。

## 4. 数值与单位

| 类别 | 写法 | 说明 |
| --- | --- | --- |
| 数字 | 阿拉伯数字（半角） | 小数、百分比、范围同样用半角：0.75、25%、1–16、-10 至 +9 |
| 中文数字 | 一、两、三……可用于小数量和近似表达 | 倍数和上限仍应精确。 [ROD_greatwood.1](source-keys.md#k-tc.research_page.ROD_greatwood.1) |
| vis | `50 vis` | 数字与单位的间距依项目惯例。 [ROD_greatwood.1](source-keys.md#k-tc.research_page.ROD_greatwood.1) |
| 厘魔 | “2 cv/t”“每 tick 每点 Ignis cv” | |
| 源质 / 要素 | “8 点源质”“4 点秩序” | 单位用“点” |
| 时间 | 20 刻（约 1 秒）、每 40 刻 | 统一使用项目的时间单位，换算后保留精度。 |
| 距离 / 范围 | 16 格、3×3、半径三格 | 尺寸统一使用乘号。 |
| 流体 | “1000 mB”“100mB” | 跟随项目惯例 |
| 能量 | “10000 FE”“80 FE/t”“4096 EU/t”“250 LP”“256 su” | 其他模组的单位原样保留 |
| 概率 | “1/1000 的概率”“25% 的概率”“有小几率” | |
| 范围符号 | “1–4”用短横或“至” | 同一文本内统一 |

数字与汉字之间是否加空格，按目标项目的惯例决定，例如 TC4Revival 现代文本加空格，原版不加。**同一文件内必须一致。**

## 5. 要素名的写法

- **拉丁名**：首字母大写，例如 Aer、Terra、Ignis、Aqua、Ordo、Perditio、Potentia、Victus。可以加颜色码，见 appendix-glossary 第二节；复合要素通常不加。
- **中文名**。沿用目标项目对要素和能量的称呼，历史写法可查[要素索引](appendix-glossary.md)。
- 同一页尽量统一采用拉丁名或项目译名。颜色、单位与正文配合的用例见 [ROD_obsidian.1](source-keys.md#k-tc.research_page.ROD_obsidian.1)、[ARCANEBORE.3](source-keys.md#k-tc.research_page.ARCANEBORE.3)。
- 有些现代渲染器会把拉丁要素名或“X 之要素”自动转为带图标的链接（TC4Revival 即如此）。这时写拉丁名或标准中文名，比写自造的简称更好。
- 数据页可以直接写“Ignis 4, Praecantatio 2”，并在旁注中说明“要素以拉丁名标注”。

## 6. 物品名的标注

- 原版习惯用 `§5物品名§0` 把物品或设备名标成紫色，**每页一般只标一两处关键物品**，用量很克制：307 页中只用了 30 次。
- 也可以用 `§l物品名§r` 加粗来强调，神秘能源、自动化魔法原作常这样做。
- 不要给每个名词都上色。

## 7. 少用或不用的词

| 词 | 原因 | 替代 |
| --- | --- | --- |
| 您、请 | 原版正文从不对读者使用敬语 | 你；“务必”“注意” |
| 用户、玩家（在叙述中） | 打破第四面墙 | 你、神秘使、佩戴者、持有者 |
| 本模组、本附属、本移植、原作、移植版 | 元信息 | 删除，或改为括号旁白 |
| 实现、代码、服务端、客户端、数据包、配置项 | 开发者用语 | “服务器”“配置”可以在括号旁白中出现；其余改写 |
| JEI | 外部工具名 | 配方查看器 |
| 灵力 | 与“灵气 / 魔力”混用，造成混乱 | 魔力（vis）或灵气（aura），视语义而定 |
| GUI、界面（过多） | 说明书腔 | 少量使用“界面”可以接受，原版也说“界面”；能说“打开它”就别说“打开 GUI” |
| 生效、触发、判定（连续使用） | 技术术语味重 | 起效、发动、会…… |
